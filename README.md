# CollabMatch 🚀
### Find Your Perfect Collaboration

CollabMatch is a modern creator and brand collaboration platform designed to connect brands with the right content creators through niche-based discovery, audience insights, and intelligent matching.

### ✨ Features
- Creator discovery and search
- Advanced category filters
- Smart creator matching
- Creator profile pages
- Save and manage creators
- Collaboration requests
- Interactive dashboard
- Responsive user interface
- LocalStorage data persistence

### 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- Lucide React

### 🚀 Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the application using `npm start`.
4. Open `http://localhost:3000`.
